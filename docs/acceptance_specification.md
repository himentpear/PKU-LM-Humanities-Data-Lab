# 考古文献数字化与交互平台 · 新报告接入验收规程与说明文档

**文档版本**：v1.2  
**适用对象**：考古数字化项目组全体成员（数据处理人员、测试验证人员、文献审校人员）  
**适用范围**：新批次考古发掘报告（含多卷本、正文卷、图版卷、线图集等）从摄入处理、入库丰富到前端交互的端到端质量验收。

---

## 1. 验收概述与目标

本规程旨在规范新考古报告接入数字化平台后的质量检验标准、操作规程与验收准则。通过规范化的测试用例与量化指标，确保系统在处理新报告时达到以下目标：
1. **版面还原与目录规整**：正文、图版、图题、页眉页脚及脚注清晰分离；全书目录层级规整，杜绝噪点，且两套目录树的叶子节点全部精确锚定至**单件器物粒度**。
2. **标本高保真分割切片**：图版页中各独立标本被完整识别与切割，动态切片清晰无畸变。
3. **跨卷知识图文互联**：打破多卷本壁垒，实现出土描述与图版标本的双向无缝跳转。
4. **多模式对比与工作台稳定性**：2D 自由排版、水平标尺对齐与叠合透视功能流畅稳定，满足考古类型学研究需求。

---

## 2. 验收环境与前置准备

### 2.1 运行环境要求
- **操作系统**：Windows 10/11, macOS, 或 Linux
- **运行环境**：Python 3.11+ 虚拟环境 (`.venv`)
- **核心数据依赖**：
  - 待验收报告处理成果库：`data/processed/library/`
  - 关系型元数据库：`library.db`（SQLite + FTS5 引擎）
  - 图像切片源文件：`data/processed/library/manifests/{manifest_id}/images/`
- **浏览器要求**：现代 Chromium 核心浏览器（Chrome / Edge 最新版，缩放比例推荐 100%）。

### 2.2 服务启动命令
在仓库根目录下激活虚拟环境并启动后台服务：
```powershell
# Windows PowerShell
.\.venv\Scripts\python.exe scripts/serve_library.py --library data/processed/library --port 8000
```
服务成功启动后，控制台应输出：
```text
Library ready at http://127.0.0.1:8000
```
在浏览器中打开 `http://127.0.0.1:8000` 即可开始验收。

## 3. 验收量化指标与合格阈值

| 维度 | 关键指标项 | 验收合格阈值 | 测量与统计方式 |
| :--- | :--- | :--- | :--- |
| **目录规整** | 题目扫描有效识别率 | ≥ 98% | 抽检 100 个各级目录节点，核对标题完整度 |
| **目录除噪** | 注释/出处/尺寸误入标题率 | **0% (绝对拦截)** | 检查目录中是否含有注码、文献引文、纯度量数据 |
| **层级粒度** | 目录叶子节点器物粒度覆盖率 | ≥ 95% | 抽查“目录全章”与“图版展厅”，确认下钻至单件器物 |
| **图像分割** | 整页多器物 BBox 召回率 | ≥ 92% | 抽查 20 个整页图版，统计标注器物总数与框出总数 |
| **切片质量** | 切片有效率与边缘完整率 | ≥ 98% | 抽检 50 个切片，确认口沿、腹部、圈足未被裁断 |
| **图文互联** | 跨卷器号规范化检索命中率 | ≥ 90% | 抽检 30 个包含全角/半角冒号的器物编号检索 |
| **双向跳转** | 正文出土记录 ↔ 图版切片跳转准确率 | ≥ 95% | 抽检 20 组器物链接，核对跳转位置与目标一致性 |
| **系统性能** | 展厅切片单张加载耗时 | ≤ 300 ms | 开发者工具 (F12) Network 监控 `/api/crop/` 响应 |
| **交互帧率** | 2D 画布多卡片拖拽流畅度 | ≥ 50 fps | 在 Lighttable 画布放置 6 件器物进行连续平移与对齐 |

## 4. 分项测试用例与执行规程

### TC-01：版面识别与阅读流向验收 (Layout & Order)

- **测试目的**：验证复杂考古双栏版面、页眉页脚及排版顺序的准确性。
- **前置条件**：在主界面文献阅览器中加载待测报告正文卷。
- **执行步骤**：
  1. 随机抽检包含双栏排版的页面（至少 10 页），检查左侧文本栏的阅读顺序。
  2. 观察正文段落首尾，核对有无被插入页眉（如卷名、章名）或页脚（如页码）。
  3. 检查插图与图题说明（如 `图一二 青瓷盏线图`），确认图题是否作为独立属性关联，未错误拼入正文长句。
- **合格标准**：
  - 双栏阅读流向严格符合“左栏上->左栏下->右栏上->右栏下”；
  - 正文中无页眉页脚干扰词；
  - 图题与正文正确定位。

---

### TC-02：题目扫描自动验证与目录层级规整 (TOC Hierarchy & Validation)

- **测试目的**：检验 `validate_heading_title` 的自动清洗能力及器物名称统一下钻能力。
- **前置条件**：打开左侧导航栏的【目录全章】与【仅图片/展厅】两套目录。
- **执行步骤**：
  1. 展开多卷本目录，逐级展开至第 4、第 5、第 6 层。
  2. 重点检查器物集中的章节（如“唐代瓷器 -> 碗 -> 青釉碗”）。
  3. 检索目录文字，排查是否包含以下特征词：
     - 注码特征：`[1]`、`[2]`、`注①`、`注（一）`
     - 引注特征：`参见《`、`见简报`、`同上`、`卷三`
     - 度量特征：`残高`、`口径`、`底径`、`壁厚`、`厘米`、`毫米`
  4. 对比“目录全章”与“仅图片”两处的最小节点名称。
- **合格标准**：
  - 目录树叶子节点规范显示为单件器物（如 `青釉划花碗 (T101②:3)` 或 `白釉执壶`）；
  - 绝对无注脚、引注、尺寸文字被错误作为章节标题；
  - 两套目录在相同器物下的命名与分类保持一致。

---

### TC-03：图版智能检测与动态切片质量验收 (Plate BBox & Crop)

- **测试目的**：验证图版大图的连通域检测精度与 `/api/crop/` 服务质量。
- **前置条件**：切换至【考古图版展厅】视图。
- **执行步骤**：
  1. 挑选 5 幅具有代表性的整页图版：
     - *密集排布型*：一页包含 6~9 件小件瓷器（如盏、杯）；
     - *大件孤立型*：一页仅包含 1~2 件大瓶或罐；
     - *残片混排型*：包含口沿、底足标本残片；
     - *线图拓片型*：拓片与剖面线图并存页面。
  2. 检查图版上红框/BBox 的覆盖情况：有无漏框、多框、过大过小。
  3. 点击卡片，调用 `/api/crop/` 生成独立高清切片。
  4. 检查切片图像边缘是否留有适度缓冲，器物口沿、底足是否完整。
- **合格标准**：
  - 单页多器物漏切率 ≤ 8%；
  - 切片主体居中，未截断器物口部或足部；
  - 切片 URL 响应速度流畅，无破图或 500 错误。

---

### TC-04：跨卷图文一体化与全文检索验收 (Cross-Volume Linkage)

- **测试目的**：验证全书目/跨卷出土记述与图版切片的双向互通性。
- **前置条件**：确保系统已加载包含“正文卷”与“图版卷”的完整多卷报告。
- **执行步骤**：
  1. **全文检索与归一化测试**：
     - 在搜索框分别输入全角与半角编号（如 `T102:15` 与 `T102：15`、`M1:3`）；
     - 检索器物器型关键词（如 `执壶`、`双系罐`、`秘色`）。
  2. **正文反查图版**：
     - 在搜索结果或正文段落中找到器物标号，点击该标号。
     - 观察是否能直接唤起对应图版切片预览。
  3. **图版回溯正文**：
     - 在图版展厅中找到任意器物切片卡片，点击【查看出土记录】。
     - 观察系统是否自动切换并定位至正文卷对应的探方/层位描述段落。
- **合格标准**：
  - 全角与半角器物编号均能 100% 检索匹配；
  - 正文至图版切片的跳转准确率 ≥ 95%；
  - 反查正文时能精准高亮或滚屏定位至出土地点描述处。

---

### TC-05：多模式自由比对工作台交互验收 (Workbench & Lighttable)

- **测试目的**：验证 2D 自由画布的考古类型学比对功能及数据审校机制。
- **前置条件**：切换至【自由比对工作台】。
- **执行步骤**：
  1. **拖拽布局测试**：
     - 从展厅或目录中挑选 4~6 件器物卡片（点击 `[+对比]`）；
     - 在画布中进行任意拖动摆放、层叠、缩放与关闭卡片。
  2. **基准参考线测试**：
     - 开启水平基准参考线；
     - 垂直拖动参考线至器物口沿处，再拉出第二根参考线对齐圈足底部；
     - 观察多件器物在同一基准线下的比例与弧度差异。
  3. **叠合透视比对测试 (Overlay)**：
     - 将两件器物卡片重叠放置；
     - 拖动透明度滑块（Opacity 0%~100%）；
     - 观察正视照片与线图/剖面图的叠合吻合度。
  4. **审校保存与版本追溯**：
     - 在阅览室修改某段错别字或器物描述，提交审校保存；
     - 刷新页面，验证 `approved_text` 是否正确保留，原始 `raw_ocr` 是否完好追溯。
- **合格标准**：
  - 画布拖拽响应灵敏，无丢帧卡顿；
  - 水平参考线吸附与测量直观准确；
  - 叠合透视功能正常平滑，无图层闪烁；
  - 审校保存机制稳定，具备版本追溯能力。

## 5. 缺陷等级划分与判定准则

| 缺陷等级 | 定义说明 | 典型现象示例 | 修复时限要求 |
| :--- | :--- | :--- | :--- |
| **P0 - 致命 (Blocker)** | 系统崩溃、主流程阻断、核心数据损坏或丢失 | 启动报错退出；数据库死锁；全卷图片切片全部报 500；目录树无法加载 | 24 小时内修复并重新出包 |
| **P1 - 严重 (Critical)** | 核心功能重大缺陷，无合理规避手段 | 题目扫描验证失效导致数百条注释侵入目录；整页图版大面积漏切；正文与图版跳转错乱 | 48 小时内修复 |
| **P2 - 一般 (Major)** | 功能存在缺陷但有替代方案，或局部交互异常 | 某个特殊编号（如带三级括号）未被正则归一化；参考线拖拽偶发偏移；个别切片边缘留白过窄 | 版本发布前修复完毕 |
| **P3 - 轻微 (Minor)** | UI 样式、字体排版、视觉微调或提示文案建议 | 展厅卡片文字换行不美观；Tooltip 提示词错别字；加载动画显示延迟 | 纳入后续体验优化迭代 |

### 5.1 验收通过准则 (Sign-off Criteria)
新考古报告数字化成果必须同时满足以下条件方可认定为**验收合格**：
1. **P0 致命缺陷**：0 项。
2. **P1 严重缺陷**：0 项。
3. **P2 一般缺陷**：累计 ≤ 3 项，且均已明确排期修复方案与规避措施。
4. 核心量化指标（第 3 节）全部达到或超过合格阈值。
